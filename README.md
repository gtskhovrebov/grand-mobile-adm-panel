# Grand Mobile Administration Panel v2.0

Внутренний инструмент администрации Grand Mobile для работы с жалобами, шаблонами и командами наказаний.

## Ссылка

https://gtskhovrebov.github.io/grand-mobile-adm-panel/

## Установка на iPhone / iPad

1. Откройте ссылку в Safari.
2. Нажмите кнопку «Поделиться».
3. Выберите «На экран Домой».
4. Подтвердите установку.

## Использование на macOS

Откройте ту же ссылку в Safari или любом современном браузере. Отдельный HTML-файл нужен только для локального тестирования.

## Возможности

- шаблоны ответов на жалобы;
- отдельные шаблоны старшей администрации;
- генератор команд наказаний;
- избранные шаблоны;
- история жалоб;
- импорт и экспорт шаблонов;
- импорт и экспорт команд наказаний;
- пользовательские шаблоны и команды;
- светлая и тёмная темы;
- интерфейс для iOS и macOS.
