# Grand Mobile Administration Panel v1.0.0

Created by John Lincoln  
for Grand Mobile Administration

## Что внутри

- `index.html` — основная панель для GitHub Pages.
- `manifest.webmanifest` — файл установки PWA на iPhone/iPad.
- `service-worker.js` — офлайн-кэш.
- `templates.json` — общие шаблоны для обычных администраторов.
- `punishments.json` — команды наказаний.
- `senior_admin_templates.json` — отдельные шаблоны для старших администраторов.
- `icon-192.png`, `icon-512.png`, `icon-180.png` — иконки приложения.

## Публикация через GitHub Pages с iPhone

1. Распакуйте ZIP в приложении «Файлы».
2. В Safari откройте репозиторий GitHub.
3. Нажмите `Code` → `Upload file`.
4. Загрузите все файлы из распакованной папки, а не сам ZIP.
5. Нажмите `Commit changes`.
6. В настройках репозитория откройте `Pages`.
7. Выберите ветку `main`, папку `/root`, сохраните.
8. После появления ссылки откройте её в Safari.
9. Нажмите «Поделиться» → «На экран Домой».

## Старшие администраторы

В общей версии нет раздела жалоб на администрацию. Чтобы он появился, старший администратор загружает внутри панели файл `senior_admin_templates.json`.
