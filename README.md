# Grand Mobile Administration Panel v2.0 for iOS

Внутреннее PWA-приложение для администрации Grand Mobile.

## Установка

1. Откройте ссылку GitHub Pages в Safari.
2. Нажмите **Поделиться**.
3. Выберите **На экран «Домой»**.
4. Подтвердите установку.

## Обновление на GitHub Pages

Загружайте в репозиторий содержимое этого архива, а не сам ZIP.

Основные файлы:

- `index.html`
- `manifest.webmanifest`
- `service-worker.js`
- `templates.json`
- `punishments.json`
- `senior_admin_templates.json`
- `icon-152.png`
- `icon-167.png`
- `icon-180.png`
- `icon-192.png`
- `icon-512.png`
