# Grand Mobile Administration Panel v2.0 for iOS

Внутренний инструмент администрации Grand Mobile.

## Установка на iPhone / iPad

1.  Откройте страницу приложения:
    https://gtskhovrebov.github.io/grand-mobile-adm-panel/

2.  Нажмите кнопку **Поделиться** в Safari.

3.  Выберите **На экран «Домой»**.

4.  Подтвердите установку.

После этого приложение будет работать как отдельное iOS-приложение.

## Обновление

После загрузки новых файлов в GitHub: - обновите страницу приложения; -
при необходимости закройте и откройте приложение снова.

## Возможности

-   Работа с шаблонами жалоб.
-   Работа с жалобами на администрацию.
-   Генерация команд наказаний.
-   Избранные шаблоны.
-   Импорт и экспорт настроек.
-   Импорт и экспорт шаблонов.
-   Импорт и экспорт команд наказаний.
-   Пользовательские шаблоны.
-   Пользовательские команды наказаний.
-   История последних жалоб.
-   Поиск по истории жалоб.
-   Светлая и тёмная темы.
