Grand Mobile Administration Panel v1.0.0 Safari / iOS

Общая версия содержит шаблоны игроков и ППЖ. Старшие администраторы могут отдельно подгрузить JSON с шаблонами на администрацию.

Шаблонные ответы

Раздел «Администрация» появится только после загрузки отдельного JSON старшей администрации.

Данные жалобы и готовый ответ

Подставлять номер жалобы в ID команды автоматически

Конструктор наказания

Поддерживаемые переменные: {complain_on}, {admin_nick}, {complain_number}, {cid}, {nick}, {punishment_type}, {punishment_duration}, {punishment_phrase}, {punishment_point}, {reason}. Приветствие и подпись добавляются автоматически.

Редактор выбранного шаблона

В самом шаблоне можно не писать приветствие и подпись: панель сама добавит «Уважаемый игрок!» сверху и «С уважением, администрация Grand Mobile.» снизу.

Готовые кнопки наказаний

Старые кнопки остались. При копировании {nick} и {cid} заменяются автоматически.
